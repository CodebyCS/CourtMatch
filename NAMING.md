# Convenções de Nomes do Projeto

1. **Idioma**: TODO o código (classes, variáveis, tabelas, DTOs) é em INGLÊS. Não misturar (ex: usar `Court`, não `Campo`).
2. **Classes e Métodos**: PascalCase (`BookingController`, `CheckAvailability`).
3. **Variáveis e Parâmetros**: camelCase (`idCampo`, `bookingDate`).
4. **Interfaces**: Começam sempre com 'I' (`IBookingService`).
