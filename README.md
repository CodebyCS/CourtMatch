# CourtMatch - Sistema de Gestão e Reserva de Campos Desportivos

O **CourtMatch** é um ecossistema composto por 4 Web APIs desenvolvidas em ASP.NET Core que permite a gestão de espaços desportivos e a reserva automatizada de campos para um clube local na zona do Grande Porto.

---

# Clonar o repositório
git clone https://github.com/CodebyCS/CourtMatch
